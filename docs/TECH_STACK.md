## For README (Detailed)

### Backend Technologies
- Django 4.2.7 - High-level Python web framework
- Python 3.8+ - Object-oriented programming language
- SQLite - Lightweight, serverless database engine
- Gunicorn 21.2.0 - Production WSGI HTTP server
- WhiteNoise 6.6.0 - Static file serving for Django

### Frontend Technologies
- Tailwind CSS (CDN) - Utility-first CSS framework
- HTML5 - Semantic markup
- JavaScript (ES6+) - Client-side interactivity
- SVG - Scalable vector graphics for icons

### Development & Deployment
- python-decouple 3.8 - Environment configuration
- Django Sessions - User session management
- Render.com - Cloud hosting platform
- Git - Version control system

### Design Patterns
- Glassmorphism - Modern UI design aesthetic
- Responsive Design - Mobile-first approach
- Component-based architecture - Reusable template structure
- Session-based authentication - No-login user experience
